# ⌨️ Typing Speed Analyzer

A responsive web application that measures typing speed, accuracy, and typing performance in real time.

## Features
- Real-time WPM (Words Per Minute)
- Accuracy calculation
- Character and mistake counting
- Timer-based typing test
- Random typing paragraphs
- Responsive and user-friendly interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension (optional).
4. Open `index.html` in your browser or run with Live Server.

## Future Improvements
- Multiple difficulty levels
- Dark mode
- User leaderboard
- Save typing history
- Different test durations
